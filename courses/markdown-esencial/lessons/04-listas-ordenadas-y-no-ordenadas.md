# Lección 4: Listas Ordenadas y No Ordenadas

En esta lección aprenderás a **organizar información en listas**.

---

## 1. Listas No Ordenadas (Viñetas)

Usa un guion `-` o un asterisco `*` seguido de un espacio para crear elementos con viñetas:

```markdown
- Manzanas
- Peras
- Naranjas
```

## 2. Listas Ordenadas (Paso a Paso)

Usa números seguidos de un punto `1.` y un espacio para listas numeradas:

```markdown
1. Encender la computadora
2. Abrir Visual Studio Code
3. Escribir tu código
```

---

## Autoevaluación

> [!QUIZ]
> ¿Qué debes agregar después del guion `-` o número `1.` para que se reconozca como una lista?
> - [ ] Un signo de igual `=`
> - [x] Un espacio en blanco
> - [ ] Una coma `,`
>
> **Explicación**: Sin el espacio posterior (ej. `-Manzana`), Markdown no sabrá que deseas crear una lista.
