# Lección 1: ¿Qué es Markdown y cómo configurar tu editor?

¡Bienvenido a la primera lección de **Markdown**! En esta lección aprenderás únicamente qué es Markdown y cómo abrir la vista previa en **Visual Studio Code**.

---

## 1. ¿Qué es Markdown?

Markdown es un lenguaje de marcado superligero que te permite dar formato a un texto usando símbolos muy sencillos. Fue diseñado para ser fácil de leer y de escribir.

A diferencia de un procesador de texto pesado (como Microsoft Word), en Markdown escribes en **texto plano** y el navegador o editor se encarga de mostrarlo con un diseño bonito.

---

## 2. Abriendo la Vista Previa en VS Code

Cuando abres un archivo con extensión `.md` en Visual Studio Code, puedes ver cómo se mostrará el documento final siguiendo estos pasos:

1. Crea o abre un archivo llamado `ejemplo.md`.
2. Presiona la combinación de teclas:
   * **En Windows/Linux:** `Ctrl + K` y luego `V` (o simplemente `Ctrl + Shift + V`).
   * **En Mac:** `Cmd + K` y luego `V` (o simplemente `Cmd + Shift + V`).
3. Se abrirá una ventana lateral en paralelo que actualizará la vista en tiempo real a medida que escribas.

> [!TIP]
> Trabajar con la pantalla dividida te permite ver el resultado instantáneamente mientras aprendes cada símbolo.
