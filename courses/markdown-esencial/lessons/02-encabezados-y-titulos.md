# Lección 2: Encabezados y Jerarquía de Títulos

En esta lección aprenderás **exclusivamente a crear títulos y subtítulos** (encabezados) en Markdown usando el símbolo `#`.

---

## 1. Símbolo `#` para Títulos

Los encabezados organizan la estructura de tu documento. La cantidad de almohadillas (`#`) determina el tamaño y la jerarquía del título:

```markdown
# Título Principal (Nivel 1)
## Sección Principal (Nivel 2)
### Subsección (Nivel 3)
#### Título Pequeño (Nivel 4)
```

> [!IMPORTANT]
> Deja siempre un espacio entre el símbolo `#` y la primera letra de tu título.
>
> * **Correcto:** `# Mi Título`
> * **Incorrecto:** `#Mi Título`

---

## Autoevaluación

> [!QUIZ]
> ¿Cuántos símbolos `#` debes colocar para crear un subtítulo de Nivel 2?
> - [ ] `#` (Uno)
> - [x] `##` (Dos)
> - [ ] `######` (Seis)
>
> **Explicación**: Dos almohadillas `##` representan un encabezado secundario (h2).
