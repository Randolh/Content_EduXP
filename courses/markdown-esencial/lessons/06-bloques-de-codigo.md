# Lección 6: Bloques de Código y Resaltado de Sintaxis

En esta lección aprenderás a **mostrar fragmentos de código de programación** con colores de resaltado.

---

## 1. Bloques de Código (Code Blocks)

Para mostrar código multilínea, encierra el texto entre tres comillas invertidas `` ``` `` arriba y tres comillas invertidas `` ``` `` abajo.

Si escribes el nombre del lenguaje de programación justo después de las primeras comillas, los colores se activarán automáticamente:

````markdown
```javascript
let saludo = "Hola Mundo";
console.log(saludo);
```
````
