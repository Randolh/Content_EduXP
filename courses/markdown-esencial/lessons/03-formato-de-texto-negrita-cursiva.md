# Lección 3: Estilos de Texto: Negrita, Cursiva y Tachado

En esta lección aprenderás a **resaltar palabras** dentro de tus párrafos utilizando negrita, cursiva y tachado.

---

## 1. Aplicando Estilos a las Palabras

Para cambiar el estilo visual de una palabra o frase, encuádrada entre asteriscos (`*`):

* **Negrita (Bold):** Encierra el texto entre dos asteriscos `**`.
  * `**Este texto es importante**` -> **Este texto es importante**
* *Cursiva (Italic):* Encierra el texto entre un solo asterisco `*`.
  * `*Este texto es inclinado*` -> *Este texto es inclinado*
* ~~Tachado (Strikethrough):~~ Encierra el texto entre dos virgulillas `~~`.
  * `~~Este texto está cancelado~~` -> ~~Este texto está cancelado~~
