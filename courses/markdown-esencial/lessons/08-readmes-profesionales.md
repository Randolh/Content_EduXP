# Lección 8: Estructura de un Archivo README.md Profesional

En esta lección final aprenderás a **combinar todos los conceptos aprendidos** para redactar la portada de cualquier proyecto: el archivo `README.md`.

---

## 1. Plantilla Básica de un README

Un buen `README.md` debe incluir:
1. **Un título principal (`#`):** Nombre del proyecto.
2. **Una descripción:** Qué hace el proyecto.
3. **Instrucciones de instalación:** Pasos en una lista o bloque de código.
4. **Licencia o contacto:** Enlace o nota final.

```markdown
# Mi Proyecto Web

Plataforma educativa creada para practicar Markdown.

## Instalación
1. Clonar el repositorio
2. Abrir `index.html` en el navegador

---
Creado por [Tu Nombre](https://github.com)
```

---

## Autoevaluación

> [!QUIZ]
> ¿Cuál es el nombre del archivo estándar que se muestra automáticamente en la portada de los repositorios de GitHub?
> - [ ] `INDEX.html`
> - [x] `README.md`
> - [ ] `DOCUMENTO.docx`
>
> **Explicación**: GitHub busca automáticamente el archivo `README.md` para renderizarlo como presentación principal del proyecto.
