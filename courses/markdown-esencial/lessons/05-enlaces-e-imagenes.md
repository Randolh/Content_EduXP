# Lección 5: Insertar Enlaces e Imágenes

En esta lección aprenderás a **conectar páginas mediante enlaces** y a **mostrar imágenes**.

---

## 1. Insertar Enlaces (Hyperlinks)

Para crear un enlace cliqueable, pon el texto visible entre corchetes `[]` y la dirección web (URL) entre paréntesis `()`:

```markdown
[Ir a Google](https://www.google.com)
```

## 2. Insertar Imágenes

La sintaxis para mostrar una imagen es casi idéntica, pero debes agregar un signo de exclamación `!` al principio:

```markdown
![Texto alternativo de la foto](https://via.placeholder.com/150)
```

> [!NOTE]
> * `[Texto](URL)` -> Crea un enlace.
> * `![Texto](URL)` -> Muestra una imagen.
