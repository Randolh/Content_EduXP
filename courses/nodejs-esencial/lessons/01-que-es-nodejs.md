# Lección 1: ¿Qué es Node.js y para qué se utiliza?

¡Bienvenido al curso de **Node.js**! En esta lección aprenderás únicamente qué es Node.js y en qué se diferencia del JavaScript que ejecutas en el navegador.

---

## 1. JavaScript fuera del Navegador

Durante muchos años, JavaScript solo podía ejecutarse dentro de un navegador web (como Chrome o Firefox) para hacer páginas interactivas.

**Node.js** es un entorno que permite ejecutar JavaScript **directamente en tu computadora o en un servidor**, sin necesidad de abrir un navegador.

---

## 2. ¿Para qué se usa Node.js?

Con Node.js puedes:
* Crear servidores web y APIs de alto rendimiento.
* Crear herramientas de línea de comandos (CLI).
* Leer y guardar archivos en el disco duro.
* Conectarte a bases de datos.

> [!NOTE]
> Node.js no es un lenguaje de programación nuevo, utiliza el mismo JavaScript que ya conoces.
