# Lección 1: ¿Qué es Express.js y para qué sirve?

¡Bienvenido al curso de **Express.js**! En esta primera lección aprenderás **exclusivamente qué es Express** y por qué es la herramienta líder para crear servidores web en Node.js.

---

## 1. ¿Por qué usar Express?

Node.js incluye un módulo nativo para crear servidores HTTP, pero requiere escribir mucho código complejo para cosas simples.

**Express.js** es un framework minimalista que simplifica la creación de:
* APIs RESTful que entregan datos JSON a aplicaciones React o móviles.
* Servidores web que responden a diferentes URLs (`/api/usuarios`, `/api/productos`).
* Sistemas de autenticación y middlewares.
