# Lección 1: ¿Qué es el Control de Versiones y por qué usar Git?

¡Bienvenido al curso de **Git y GitHub**! En esta primera lección aprenderás únicamente el concepto básico de control de versiones y por qué es indispensable para cualquier desarrollador.

---

## 1. El Problema de las Copias de Archivos

¿Alguna vez has guardado archivos con nombres como `proyecto_v1.zip`, `proyecto_final.zip`, `proyecto_final_FINAL.zip`?

El problema de este método es que rápidamente se vuelve caótico, ocupa espacio innecesario y es muy fácil perder cambios.

---

## 2. ¿Qué es un Sistema de Control de Versiones?

Un **Sistema de Control de Versiones (VCS)** es como una máquina del tiempo para tu código. Te permite:
* Guardar "fotografías" (puntos de control) de tu proyecto.
* Volver a cualquier punto del pasado si cometiste un error.
* Ver exactamente qué cambió en cada archivo.

**Git** es la herramienta de control de versiones más usada del mundo. Funciona en tu propia computadora y no requiere conexión a Internet para guardar tu historial.
