# Lección 1: ¿Qué es React y el enfoque basado en Componentes?

¡Bienvenido al curso de **React**! En esta primera lección aprenderás **exclusivamente qué es React** y por qué la arquitectura basada en componentes revolucionó el desarrollo frontend.

---

## 1. El Concepto de Componente

En una página web tradicional (HTML plano), todo el documento está en un archivo gigante.

En **React**, divides la pantalla en piezas independientes de interfaz llamadas **Componentes**:
* Un componente para el Encabezado (Header).
* Un componente para la Tarjeta de Producto (Card).
* Un componente para el Botón de Compra (Button).

Cada componente junta su estructura (HTML), sus estilos (CSS) y su lógica (JavaScript).
